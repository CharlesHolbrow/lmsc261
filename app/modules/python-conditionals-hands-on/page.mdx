## Part 4: `if` vs `elif`

<Goal>Fix <code>tempo</code> so a fast BPM is labeled <code>"fast"</code>, not <code>"medium"</code>.</Goal>

Run this as-is first and you will see `tempo(150)` print `medium`. Change one `if` to `elif` so only the first matching label is used.

<PyScriptEditor
  kind="py-editor"
  rows={14}
  outputRows={2}
  initialCode={`
def tempo(bpm):
    speed = "slow"
    if bpm > 140:
        speed = "fast"
    if bpm >= 100:
        speed = "medium"
    return speed

print(tempo(150))
print(tempo(120))
print(tempo(80))
`}
  verifyCode={`
assert tempo(150) == "fast", "150 BPM should be fast. Did both ifs still run?"
assert tempo(120) == "medium", "120 BPM should be medium"
assert tempo(80) == "slow", "80 BPM should be slow"
print("✓ Correct!")
`}
/>

### Steps

1. Open the homework repo in [GitHub Desktop](https://desktop.github.com/)
2. Switch to **`main`**
   - Current Branch → `main`
3. **Fetch or Pull Sync** the latest version of the main branch
   - Fetch origin → Pull origin
4. Make a **branch** named `your-name-hands-on-3`
   - Current Branch → New Branch
   - Example: `ada-lovelace-hands-on-3`
5. Open the `lmsc261-homework` folder in [Visual Studio Code](https://code.visualstudio.com/)
   - File → Open Folder… → choose `lmsc261-homework`
   - Or in GitHub Desktop: Repository → Open in Visual Studio Code
6. In **your** folder, make a new directory called `hands-on-3`
7. Put a `main.py` in it. Copy your working functions from the editors above. Add a few `print` calls so you can see the results when you run the file.
8. **Run** `main.py` in VS Code
   - Open the file, then click the ▶ play button in the top-right
   - Output appears in a panel at the bottom
9. **Commit** in GitHub Desktop — short message, then Commit
10. **Push** (upload) to GitHub
11. Click **Create Pull Request**
12. Title: `Your Name Hands-On 3`
13. Create the PR, but 🚨 do not click **`Merge`** 🚨
