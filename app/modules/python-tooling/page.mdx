# Python Tooling

It is common to use other people's code in your own Python projects.

For example, you can use libraries for things like:

- Reading and writing MIDI files
- Audio processing
- Image processing
- Video processing
- Text processing
- Downloading websites
- Creating websites
- Creating GUIs
- Creating games

There are Python tools for automatically downloading existing libraries.

Unfortunately, these tools are old-fashioned, overlapping, and not always user-friendly.

# Python Tool: `uv`

For this class, we will use [Astral uv](https://docs.astral.sh/uv/).

`uv` is a modern command-line tool that mitigates some of the problems caused by
older tools like `pip` and `venv`.

You can install it now by copying this line into your terminal.

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

## Set Up a Python Project with `uv`

`cd` into your folder in the homework repo.

```bash
cd ~/Documents/GitHub/lmsc261-homework
cd your-name
```

Use `uv` to set up a project named `hands-on-2`.

```bash
# Set up our Python environment
uv init --no-package hands-on-2
cd hands-on-2
uv run main.py
```

What are the commands above doing?

- `uv init` creates a new directory with helper files for a new Python project
- `cd` (change directory) moves into the new project directory
- `uv run main.py` runs the default `main.py` file created by `uv init`

If it is working correctly, the `uv run` command will print `Hello from
hands-on-2!` in the terminal.

## Adding an external library

The `uv add` terminal command will download code for writing MIDI files. This
will let you run functions from the `MIDIUtil` library in your new `hands-on-2`
project.

```bash
uv add MIDIUtil
```

Here, `MIDIUtil` is the name of a code library we want to add. We will use this
library in the next module.
