# Python: The Bad Parts

It is common to use other people's code in your own Python projects.

For example, you can use libraries for things like:

- Reading and MIDI files
- Audio processing
- Image processing
- Video processing
- Text processing
- Downloading Websites
- Creating Websites
- Creating GUIs
- Greating Games

There are python tools for automatically downloading existing libraries. 

Unforunately, these tools are old-fashined, overlapping, and are not always user friendly.

## Many Environments for Running Python

- `python my_script.py` in the terminal
- `python` Read Eval Print Loop (REPL) in the terminal
- VS Code Interactive
- Jupyter Notebooks
- VS Code with [Jupyter Notebooks Extension](https://code.visualstudio.com/docs/datascience/jupyter-notebooks)
- Google Colab
- In the Browser via [PyScript](https://pyscript.net/)

## Many ways to install Python

- Download from [python.org](https://www.python.org/downloads/)
- `brew install python`
- `conda create -n myenv python=3.11 -y`
- `conda env create -f environment.yml`
- `uv python pin 3.12`

## Many ways to add and install dependencies

- `pip install torch`
- `pip install -r requirements.txt`
- `pip install -e .`
- `conda install -c pytorch pytorch`
- `conda env create -f environment.yml`
- `conda env update -f environment.yml`
- `uv init && uv add torch`
- `uv sync`
