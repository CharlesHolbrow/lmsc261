## It's easier than you think

- Computers use **sequences of numbers** to represent:
    - **actions** like mouse, keyboard, and MIDI events
    - **data** like text, images, and audio
- All of programming: transform numbers. **That's it!**

```python
# Transforms letters into numbers and numbers into letters
a_number = ord("a")
a_letter = chr(97)

# Transform a sequence of letters into numbers
for letter in "abcdef":
    number = ord(letter)
    print(number)
```

Modern programming tools help us:
- Think **more** about abstractions
- Think **less** about numbers
