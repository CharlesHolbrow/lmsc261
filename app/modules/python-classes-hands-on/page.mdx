## Part 3: Add `self`

<Goal>Add <code>self</code> so <code>n.describe()</code> can run.</Goal>

Run this as-is first. `n.describe()` raises a `TypeError` because Python passes the object automatically, and `describe` is not ready to receive it. Add `self` as the first parameter.

<PyScriptEditor
  kind="py-editor"
  rows={12}
  outputRows={1}
  initialCode={`
class Note:
    def describe():
        print("a note")

n = Note()
n.describe()
`}
  verifyCode={`
n = Note()
n.describe()
print("✓ Correct!")
`}
/>

`n.describe()` passes `n` in as the first argument. The parameter that receives it is named `self`.
