# Local Python

A free in-browser alternative to DataCamp Light. This uses [Pyodide](https://pyodide.org/) (CPython compiled to WebAssembly). [PyScript](/modules/pyscript/) is a separate HTML layer that can run Pyodide or MicroPython.

There is a real `pyodide` npm package, but it still downloads the interpreter from a CDN. This page loads that same official script:

`https://cdn.jsdelivr.net/pyodide/v314.0.7/full/pyodide.js`

Code runs **in your browser**. Nothing is sent to DataCamp. The first load downloads the Python runtime (a few megabytes).

Press **Run**, or **⌘Enter** / **Ctrl+Enter**.

## Basic Chords starter

This is the starter from [Basic Chords](/assignments/basic-chords/). Use it to try the Ideas extras before you put them in your homework repo.

<LocalPython
  minHeight={420}
  initialCode={`
def build_major_triad(root_note_number):
    root = root_note_number
    third = root_note_number + 4
    fifth = root_note_number + 7
    return [root, third, fifth]

def build_minor_triad(root_note_number):
    root = root_note_number
    third = root_note_number + 3
    fifth = root_note_number + 7
    return [root, third, fifth]

def build_dominant_seventh(root_note_number):
    root = root_note_number
    third = root_note_number + 4
    fifth = root_note_number + 7
    seventh = root_note_number + 10
    return [root, third, fifth, seventh]

def note_name(note_number):
    notes = ["C", "C#", "D", "D#", "E", "F", "F#", "G", "G#", "A", "A#", "B"]
    list_index = note_number % 12
    letter = notes[list_index]
    note_octave = (note_number // 12) - 1
    return f"{letter}{note_octave}"

def numbers_to_names(note_numbers):
    notes = []
    for note_number in note_numbers:
        notes.append(note_name(note_number))
    return notes

chord_1 = build_major_triad(60)
chord_2 = build_minor_triad(62)
chord_3 = build_dominant_seventh(67)

for chord in [chord_1, chord_2, chord_3]:
    note_names = numbers_to_names(chord)
    print(note_names)
`}
/>
