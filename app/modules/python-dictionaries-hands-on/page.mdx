## Part 4: Missing keys

<Goal>Return the notes when <code>name</code> is in <code>chords</code>, and an empty list otherwise.</Goal>

Run this as-is first. `lookup(chords, "Dm")` raises a `KeyError`. Use `in` so a missing name returns `[]` instead of crashing.

<PyScriptEditor
  kind="py-editor"
  rows={14}
  outputRows={1}
  setup={`
chords = {
    "C": ["C", "E", "G"],
    "G": ["G", "B", "D"],
    "Am": ["A", "C", "E"],
}
`}
  initialCode={`
def lookup(chords, name):
    return chords[name]

print(lookup(chords, "Am"))
print(lookup(chords, "Dm"))
`}
  verifyCode={`
assert lookup(chords, "Am") == chords["Am"], "Am is a key; return its notes"
assert lookup(chords, "C") == chords["C"], "C is a key; return its notes"
assert lookup(chords, "Dm") == [], "A missing name should return an empty list"
assert lookup(chords, "am") == [], "Keys are case-sensitive; am is not Am"
print("✓ Correct!")
`}
/>
