# DataCamp Light Test

This page embeds [DataCamp Light](https://github.com/datacamp/datacamp-light) with their CDN script, not an npm package.

Code runs on DataCamp's servers. Students can **Run** or **Submit** in the browser.

## Graded exercise

Create a variable `a` equal to `5`, then print it.

<DataCampExercise
  id="python-variable-a"
  lang="python"
  showRunButton
  preExerciseCode="# no pec"
  sampleCode={`
# Create a variable a, equal to 5

# Print out a
`}
  solution={`
# Create a variable a, equal to 5
a = 5

# Print out a
print(a)
`}
  sct={`
test_object("a")
test_function("print")
success_msg("Great job!")
`}
  hint="Use = to create the variable a, then call print(a)."
/>
