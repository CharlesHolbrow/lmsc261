# PyScript

[PyScript](https://pyscript.net/) is a layer on top of [Pyodide](https://pyodide.org/).

- **Pyodide** is CPython compiled to WebAssembly.
- **PyScript** is HTML tags and helpers. `type="py"` and `type="py-editor"` run **Pyodide**.

Press **Run**, or **⌘+Enter** / **Ctrl+Enter** in the editor. The interpreter downloads the first time you run.

## Pyodide editor (`py-editor`)

PyScript draws a CodeMirror editor and runs the code with Pyodide.
