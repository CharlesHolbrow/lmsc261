# Content Questions: Hands-On

In class: put a `README.md` in the [homework repo](https://github.com/berklee-epd/lmsc261-homework) and open a **pull request**.

Everyone in the class will be able to see your answers.

You already know how to open a PR. New branch, work **inside** your folder, do not merge.

If you forgot the GitHub Desktop steps, see [Your First PR](/assignments/your-first-pr/).

## Steps

1. In [GitHub Desktop](https://desktop.github.com/), switch to **`main`** and **Fetch or Pull Sync**
2. Make a **branch** named `your-name-content-questions`
3. In **your** folder, make a directory called `content-questions`
4. Put a `README.md` in it. Copy the template below and answer the questions.
5. **Commit**, **Push**, then **Create Pull Request**
6. Title: `Your Name Content Questions`
7. 🚨 Do not click **Merge** 🚨

## README.md

```markdown
# (Your Name Here)

## Something we skipped or only covered briefly

What is one topic from class that you wish you understood better?

**Your answer here**

## Something you wish you could create or do

What is one piece of software you wish you could create?
Or one thing you wish you could do on your computer, but can't?

**Your answer here**

## Comments or observations (optional)

Anything you want to say about what you have learned in this class so far.

**Your answer here**
```

## Done when

```
your-name/
└── content-questions/
    └── README.md
```

Your PR is open on GitHub. You did **not** merge it.

Do not work on `main`. Do not merge the PR. Change only files in your folder.
