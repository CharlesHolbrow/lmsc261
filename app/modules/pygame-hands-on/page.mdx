        ```bash

        ```
    - add the `pygame-ce` library
        ```bash
        uv add pygame-ce
        ```
1. Open the `pygame-hands-on` folder in Visual Studio Code.
    - File → Open Folder… → choose `pygame-hands-on`
    - 🚨 **Do not open the parent homework folder!** 🚨
    - Opening the correct folder helps VS Code find the `pygame-ce` library and
      other project files.
1. Copy the following example code into the `main.py` file.
    ```python
    import pygame

    # Setup (Don't worry if you don't understand this yet)
    pygame.init()
    screen = pygame.display.set_mode((400, 400), vsync=1)
    clock = pygame.time.Clock()

    # Draw a black background
    screen_color = (0, 0, 0)
    screen.fill(screen_color)

    # Draw a red line
    draw_color = (255, 0, 0)
    start = (0, 0)
    end = (400, 400)
    pygame.draw.line(screen, draw_color, start, end)

    # Update the display
    pygame.display.flip()

    # Game loop (Don't worry if you don't understand this yet)
    running = True
    while running:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                running = False

        clock.tick(60)

    pygame.quit()
    ```
1. Verify that your project is set up correctly by running the code. You can:
    - Press the Run (▶) button in VS Code while `main.py` is open
    - Or in the terminal, run `uv run main.py`

If your project is set up correctly, you will see a black window with a red line
from the top left to the bottom right. When you have this working, continue to Part 2.
