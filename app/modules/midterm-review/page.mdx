## Two kinds of functions:

These two patterns look similar, but the **order of the pieces** is different. ([Why?](https://stackoverflow.com/questions/83983/why-isnt-the-len-function-inherited-by-dictionaries-and-lists-in-python))

- **How many items?** `len(my_list)`. This is called a "global" function. 
- **Add to this list?** `my_list.append(7)`

The code below mixes up those patterns. Fix it so `my_list_length` is how many items are in `my_list`, and `my_list` ends with `4` on the end.

<PyScriptEditor
  kind="py-editor"
  rows={10}
  outputRows={2}
  initialCode={`
my_list = [1, 2, 3]
my_list_length = my_list.len()  # Wrong!
append(my_list, 4)              # Wrong!

print("length:", my_list_length)
print("list:", my_list)
`}
  verifyCode={`
assert my_list_length == 3, f"Expected length 3, got {my_list_length!r}"
assert my_list == [1, 2, 3, 4], f"Expected [1, 2, 3, 4], got {my_list!r}"
print("✓ Correct!")
`}
/>
