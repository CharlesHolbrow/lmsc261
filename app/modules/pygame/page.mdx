# Pygame

Pygame Community Edition [pygame-ce](https://pyga.me/) is a python library for making games and
interactive programs.

We will use it for opening a window, drawing shapes, and reading the mouse and keyboard input.

## Set up a project

`cd` to where you want to store your project. For homework assignments this will
look like `cd ~/Documents/GitHub/lmsc261-homework/your-name`.

Then, Create a new project and move into it.

```bash
uv init --no-package pygame-sketches
cd pygame-sketches
uv run main.py
```

`uv init` makes a project folder with a starter `main.py`. `uv run main.py`
should print `Hello from pygame-sketches!`

Add the library, then run `main.py` again whenever you change it.

```bash
uv add pygame-ce
```

## Sketch 1: Draw a line

Replace the starter `main.py` with this. Close the window when you are done
looking.

```python
import pygame

# Setup (Don't worry if you don't understand this yet)
pygame.init()
screen = pygame.display.set_mode((400, 400), vsync=1)
clock = pygame.time.Clock()

# Draw a black background
screen_color = (0, 0, 0)
screen.fill(screen_color)

# Draw red lines
draw_color = (255, 0, 0)
start = (0, 0)
end = (400, 400)
pygame.draw.line(screen, draw_color, start, end)

# Update the display
pygame.display.flip()

# Game loop (Don't worry if you don't understand this yet)
running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    clock.tick(60)

pygame.quit()
```

`set_mode` opens the window. `fill` paints the background. Colors are
`(red, green, blue)` tuples from `0` to `255`.

`pygame.draw.line` takes the screen, a color, and two `(x, y)` points.

`flip()` copies what you drew onto the real window. The `while` loop keeps the
window open until you close it. Without that loop, the window would appear and
immediately disappear.

## Sketch 2: Drawing in a for loop

data = [0, 10, 25, 40, 60, 85, 125, 170, 230]

Draw several lines at x positions `[0, 10, 25, 40, 60, 85, 125, 170, 230]`

Copy the following into the render section of `main.py`

```python
# Draw red lines
data = [0, 10, 25, 40, 60, 85, 125, 170, 230]
for x in data:
    draw_color = (255, 0, 0)
    start = (x, 0)
    end = (x, 400)
    pygame.draw.line(screen, draw_color, start, end)
```
