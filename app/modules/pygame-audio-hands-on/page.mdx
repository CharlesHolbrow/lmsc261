# Pygame Audio: Hands-On

In class: clone the course repo, open the `pygame-audio` project in Visual Studio Code, and run it.

You already have access to the [course repo](https://github.com/berklee-epd/lmsc261). This project lives there, not in the homework repo.

`pygame-audio` is a pygame window that plays a pitched sample of `c4.wav`.

## Part 1

### Goals

1. Clone the course repo
1. Open the `pygame-audio` folder in Visual Studio Code
1. Follow `README.md` and run the project

### Steps

1. In GitHub Desktop, clone [berklee-epd/lmsc261](https://github.com/berklee-epd/lmsc261). You already have access.
    - File → Clone repository…
    - Choose the **URL** tab
    - Paste `https://github.com/berklee-epd/lmsc261`
    - Clone
1. Open the `pygame-audio` folder in Visual Studio Code.
    - File → Open Folder… → choose `pygame-audio` inside the repo you just cloned
    - **Note:** Opening the correct folder helps VS Code find this project's Python environment
1. Follow the setup and run instructions in the `pygame-audio` `README.md`.

If the folder is open correctly, the Explorer shows `main.py`, `audio.py`, `c4.wav`, and `README.md`.

Part 1 is finished when the project is running.
