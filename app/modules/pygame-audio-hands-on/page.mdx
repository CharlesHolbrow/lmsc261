# Pygame Audio: Hands-On

In class: clone the course repo, copy `pygame-audio` into your folder in the homework repo, run `uv sync`, then open that copy in Visual Studio Code and run it.

You already have access to the [course repo](https://github.com/berklee-epd/lmsc261). The starter project lives there. Copy it into the folder with your name in the [homework repo](https://github.com/berklee-epd/lmsc261-homework), and do the rest of your work in that copy.

`pygame-audio` is a pygame window that plays a pitched sample of `c4.wav`.

## Part 1

### Goals

1. Clone the course repo
1. Copy `pygame-audio` into the folder with your name in the homework repo
1. Run `uv sync` in that copy, so `.venv` exists before Visual Studio Code opens
1. Open that copy in Visual Studio Code
1. Run the project

### Steps

1. In GitHub Desktop, clone [berklee-epd/lmsc261](https://github.com/berklee-epd/lmsc261). You already have access.
    - File → Clone repository…
    - Choose the **URL** tab
    - Paste `https://github.com/berklee-epd/lmsc261`
    - Clone
1. Copy the `pygame-audio` folder from the course repo into the folder with your name in the homework repo. The result should be `lmsc261-homework/<your-name>/pygame-audio`.
1. In the terminal, `cd` into that copy and create the virtual environment before you open Visual Studio Code:
    ```bash
    cd ~/Documents/GitHub/lmsc261-homework/<your-name>/pygame-audio
    uv sync
    ```
    `uv sync` creates `.venv`. Visual Studio Code can only find this project's Python environment after that folder exists.
1. Open that copy in Visual Studio Code.
    - File → Open Folder… → choose `pygame-audio` inside your named homework folder
    - 🚨 **Do not open the copy in the course repo, or the parent homework folder.** 🚨
    - If Visual Studio Code asks you to select a Python interpreter, choose the one inside `.venv`
1. Run the project: `uv run main.py`, or open `main.py` and press the Run (▶) button.

If the folder is open correctly, the Explorer shows `main.py`, `audio.py`, `c4.wav`, and `README.md`.

Part 1 is finished when the project is running.
