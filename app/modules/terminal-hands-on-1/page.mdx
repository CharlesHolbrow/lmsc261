# Terminal Hands-On

In class: walk around your computer with `cd` and `cd ..`, then open the folder you landed in with Finder. When that feels easy, keep going on your own with Part 2.

You should already have read [The Terminal](/modules/terminal/).

## Terminal Hands-On Part 1

### Part 1 Goals

1. See where you are (`pwd`) and what's in the folder (`ls`)
2. Move into a folder with `cd` and back out with `cd ..`
3. Open the current folder in Finder with `open .`

### Part 1 Steps

1. Open **Terminal**
   - `Cmd + Space` → type `Terminal` → Enter
   - Or in VS Code: Toggle Terminal (`` Ctrl + ` ``)
2. Go **home**, then type these **one at a time**. After each one, read what the computer says back.

```
cd ~
pwd
ls
cd Documents
pwd
ls
open .
cd ..
pwd
```

3. After `pwd`, you should see something like `/Users/your-name`. That folder is **home**. `cd ~` takes you there even if the terminal opened somewhere else.
4. After `ls`, you should see folders like `Desktop`, `Documents`, `Downloads`.
5. After `cd Documents`, the next `pwd` should end with `/Documents`.
6. `open .` opens **this** folder in Finder. `.` means this folder. Look at Finder and at `pwd`. They match.
7. `cd ..` goes **up** one folder. The last `pwd` should be `/Users/your-name` again.
8. Practice. Pick another folder (`Desktop`, `Downloads`, …). `cd` in, `pwd`, `ls`, `open .`, then `cd ..` to come back.

If a name has a space, wrap it in quotes: `cd "Screen Recordings"`.

Lost? `cd ~` takes you home. Then `pwd`.

### Commands

```
pwd          # where am I?
ls           # what's in this folder?
cd Documents # go into Documents
cd ..        # go up one folder
cd ~         # go home
open .       # open this folder in Finder
```

- `..` = up one folder
- `../..` = up two folders
- `~` = home
- `.` = this folder

Your home folder looks like this. `cd` moves you around it.

```
/Users/your-name     ← home (~)
├── Desktop
├── Documents        ← cd Documents
└── Downloads
```

When you are in `Documents`, `cd ..` goes up to `/Users/your-name`.

### Done when

You can:

- `cd` into a folder and `cd ..` back out
- Use `pwd` to say where you are
- Use `open .` and see that folder in Finder

Then keep going with [Part 2](#terminal-hands-on-part-2).

## <span id="terminal-hands-on-part-2">Terminal Hands-On Part 2</span>

### Part 2 Goals

1. Try commands you have not used yet
2. Notice whether each one wants a **file**, a **folder**, a **program name**, or just **text**
3. Explain what each one does, in your own words

For each command: run the example. Read what comes back. Then say what you think it does.

If a path does not work, pick another file you can see with `ls`. Use names that exist on your computer.

### mkdir

`mkdir` is run on a folder name. Try it in a folder of yours (`Documents`, your homework folder, …).

```
mkdir practice
```

Then `ls`. Is it there? `cd` into it.

### touch

`touch` creates an empty file. Give it a name.

```
touch notes.txt
```

Then `ls`. Run `cat` on it.

### which

`which` is run on a program name, not a file.

```
which python3
which git
```

What did it print? What is `which` telling you?

### echo

`echo` is not run on a file. Type some text after it.

```
echo hello
echo $HOME
```

What did each one print? What does `echo` do?

### More `ls`

You already know `ls`. A letter after a hyphen is a **flag**. Try these **one at a time**.

```
ls -l
ls -a
ls -h
ls -lh
```

What does each letter change? Why might `-h` look different when combined with `-l` than it does alone?

### du

`du` is run on a file or folder.

```
du -h .
```

If that prints a lot, you are in a big folder. Try a smaller one, or add `-s`.

What is `du` measuring? Hint: `du` stands for "disk usage".

### cat

`cat` prints the contents of a file. Run it on a text file you can see with `ls`.

```
cat filename.txt
```

### head

`head` is run on a file. Same kind of argument as `cat`.

```
head ~/.zshrc
```

How is that different from `cat`?

### file

`file` is run on a file.

```
file ~/.zshrc
file /usr/bin/python3
```

What is it telling you about each path?

### man

`man` is run on a command name. It opens a manual. Press **`q`** to quit.

```
man ls
```

Use `man` on any command from this page when you want more detail.

### Done when

You can explain, in your own words, what `which`, `echo`, `ls -l`, `ls -a`, `ls -h`, `du`, `head`, `file`, `man`, and `mkdir` do. You have run `cat` on a text file and used `touch` to make one.
