# The Terminal

A text box. You type commands. The computer talks back.

Open it: `Cmd + Space` → type `Terminal`

Or in VS Code: `` Ctrl + ` `` is the default **Toggle Terminal** keybinding.

## pwd

Where am I?

```bash
pwd
```

## ls

What's in this folder?

```bash
ls
```

## cd

Go to a folder.

```bash
cd Documents
cd ..
cd ~
```

- `..` = up one folder
- `~` = home

## which

Where is this program?

```bash
which python
which git
```

## open

Open a file, folder, or app (Mac).

```bash
open .
open README.md
open -a "Visual Studio Code"
```

`.` = this folder
