# The Terminal

The terminal is a text input box. You type commands and submit them with `Enter`. The computer responds.

Like python, the terminal has its own language, called a `shell`. The shell
determines valid syntax and what kinds of commands are available. On Mac, `zsh` is
the default shell. `bash` is another common shell that is VERY similar to `zsh`.

To open a terminal: `Cmd + Space` → type `Terminal`

Or in VS Code: `` Ctrl + ` `` is the default **Toggle Terminal** keybinding.

## pwd

Where am I?

```bash
pwd
```

## ls

What's in this folder?

```bash
ls
```

## cd

Go to a folder.

```bash
cd Documents
cd ..
cd ~
```

- `..` = up one folder
- `~` = home

**Tab autocomplete** is can help you avoid typos. Type the first few letters
of a folder name and press `Tab`. The terminal will suggest the full name. 

For example, type `cd ~/Doc` and press `Tab` to autocomplete to `cd ~/Documents`.

## which

Where is this program?

```bash
which python
which git
```

## open

Open a file, folder, or app (Mac only).

```bash
open .
open README.md
open -a "Visual Studio Code"
```

`.` = this folder
