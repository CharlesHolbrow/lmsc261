## Terminal Question 1

Your current directory is:

```
/Users/ada/Documents/GitHub/lmsc261-homework/
```

**Q:** What command changes the directory to `assignment-4`?

1. `cd /ada-lovelace/assignment-4`
2. `cd ada-lovelace/assignment-4`
3. `cd ~/ada-lovelace/assignment-4`
4. `cd assignment-4`

<Toggle title="Answer">

**2.** `cd ada-lovelace/assignment-4` — a relative path from your current folder.

Option 1 starts at the filesystem root (`/`), not from `lmsc261-homework`. Option 3 uses `~` (home), which is `/Users/ada`, not the homework repo. Option 4 skips the `ada-lovelace` folder.

</Toggle>

## Terminal Question 2

Your current directory is:

```
/Users/ada/Documents/GitHub/lmsc261-homework/ada-lovelace
```

**Q:** Which command sequence would take you to `/Users/ada/Documents/GitHub/`?

1. `cd ..` (do this three times)
2. `cd ..` (do this twice)
3. `cd ...` (do this twice)
4. `cd .` (do this three times)

<Toggle title="Answer">

**2.** Run `cd ..` twice: up to `lmsc261-homework`, then up to `GitHub`.

`...` is not valid shell syntax. `.` means “this directory,” so `cd .` does not move you.

</Toggle>

## Terminal Question 3

**Q:** In the terminal, what do you type to show the contents of the current directory?

<Toggle title="Answer">

```bash

```

</Toggle>

</Toggle>

## Terminal Question 5

Your current directory is:

```
/Users/ada/Documents/GitHub/lmsc261-homework/
```

**Q:** What sequence of commands would you use to enter the `ada-lovelace` homework directory, then create a new Python project named `quiz-1` with `--no-package`?

<Toggle title="Answer">

```bash
cd ada-lovelace
uv init quiz-1 --no-package
```

`uv init --no-package quiz-1` is also fine.

</Toggle>

After those commands, your tree looks like this:

```
/Users/ada                   ← home (~)
├── Desktop
└── Documents
    └── GitHub
        └── lmsc261-homework
            └── ada-lovelace
                ├── assignment-4
                └── quiz-1
                    ├── main.py
                    ├── pyproject.toml
                    └── README.md
```

## Terminal Question 6

**Q:** After creating the project, what sequence of commands do you need to `cd`
into the new project directory and run the generated `main.py` file?

<Toggle title="Answer">

```bash
cd quiz-1
uv run main.py
```

Run these from `ada-lovelace` (where you were after Question 5).

</Toggle>
