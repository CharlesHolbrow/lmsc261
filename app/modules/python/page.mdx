## Python Dictionaries

Dictionaries store **key-value pairs**. They're everywhere in Python and machine learning—configuration, data records, and more.

```python
# Create a dictionary
person = {"name": "Alice", "age": 25}

# Access values
print(person["name"])  # "Alice"

# Add or update
person["instrument"] = "piano"
person["age"] = 26

# Loop through
for key, value in person.items():
    print(f"{key}: {value}")
```

```python
data = {}
data[0] = "zero"
data[1] = "one"
data[2] = "two"

# Test yourself:

```

## Python Classes

Classes bundle **data** and **functions** together. The `__init__` method runs when you create an instance, and `self` refers to that instance.

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def add(self, other):
       return Vector(self.x + other.x, self.y + other.y)


a = Vector(1, 2)
b = Vector(3, 4)
print("a.x =", a.x)
print("a.y =", a.y)
print("a.add(b) =", a.add(b))
```

## Python Operator Overloading

Python lets you define certain "dunder" (double underscore) methods which have
special meaning. The `__repr__` method is used to define the string
representation of the object.

```python
class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __repr__(self):
        return f"({self.x}, {self.y})"

a = Vector(1, 2)
b = Vector(3, 4)

print("a =", a)
print("b =", b)
```

**Callable class instances** You can make your class instances operate like a function with `__call__`.

```python
class Multiplier:
    def __init__(self, factor):
        self.factor = factor

    def __call__(self, x):
        return x * self.factor

# You can now execute the __call__ method with `obj(...)` instead of `obj.__call__(...)`

double = Multiplier(2)
print(double(5))   # 10
print(double(21))  # 42

triple = Multiplier(3)
print(triple(2))
print(triple(3))
```

**Attribute interception:** You can also intercept attribute access with `__getattr__` and `__setattr__`.

```python
class Tracked:
    def __setattr__(self, name, value):
        print(f"Setting {name} = {value}")

obj = Tracked()
obj.x = 10  # prints "Setting x = 10"
```

# Notebooks

Jupyter Notebooks (`.ipynb` files) combine code, output, and documentation in a
single interactive document. Code runs in **cells** that can be executed
independently.

```bash
uv add notebook torch
uv run jupyter notebook
```

You can also use the [Jupyter extension for VSCode](https://open-vsx.org/extension/ms-toolsai/jupyter)
to run notebooks. If you do, it's a good idea to open the folder with the
pyproject.toml file in VS Code. This can make it easier for the extension to
find the correct environment.

### Essential Hotkeys

| Key                | Action                                        |
| ------------------ | --------------------------------------------- |
| `Shift + Enter`    | Run cell, move to next                        |
| `Ctrl/Cmd + Enter` | Run cell, stay in place                       |
| `Esc`              | Enter command mode (cell operations)          |
| `Enter`            | Enter edit mode (typing)                      |
| `A` / `B`          | Insert cell above / below (command mode)      |
| `DD`               | Delete cell (command mode)                    |
| `M` / `Y`          | Change cell to Markdown / Code (command mode) |

### Basic Workflow

1. Write code in a cell
2. Run with `Shift + Enter`
3. Output appears below the cell
4. Variables persist across cells (run order matters!)
