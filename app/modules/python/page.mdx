# Python Basics

A **variable** stores a value under a name. Two kinds you'll use constantly are **numbers** and **strings**.

## Numbers

Like many programming languages, in Python, you can assign values to named variables with an equals sign `=`.
 
```python
beats_per_measure = 4
measures = 8
total_beats = beats_per_measure * measures
print(total_beats)  # 32

bpm = 120
seconds_per_beat = 60 / bpm
print(seconds_per_beat)  # 0.5

score = 95.5
bonus = 2
print(score + bonus)  # 97.5
print(score - bonus)  # 93.5
```

## <span id="strings">Strings</span>

A **string** is text in quotes. Strings can also be assigned to variables.

```python
name = "Alice"
instrument = "piano"

print("Hello")
print(name)
print(instrument)
```

## <span id="formatting-strings">Formatting Strings</span>

Assign it to a name, then `print` it. Do you see the `f` before the first `"` below? 

An **f-string** (the `f` before the quotes) lets you drop variables into a sentence with `{curly braces}`.
```python
name = "Alice"
score = 95.5
assignment_number = 1
message = f"{name} received a {score} on assignment #{assignment_number}"

print(message)
```

## Lists

A **list** holds items in order. You look items up by **index** (counting starts at `0`) and add items with `.append()`.

```python
# A C major triad
chord = ["C", "E", "G"]

# Access notes by index
print(chord[0])  # "C"
print(chord[2])  # "G"

# Add the seventh
chord.append("B")

# How many notes are in the chord?
print(len(chord))  # 4

# Change the third
chord[1] = "Eb"
```

## Dictionaries

Dictionaries store **key-value pairs**. They're everywhere in Python: configuration, data records, and more.

```python
# Create a dictionary
person1 = {
    "name": "Alice",
    "age": 25,
    "instrument": "piano",
    "score": 95.5
}

person2 = {
    "name": "Bob",
    "age": 30,
    "instrument": "guitar",
    "score": 85.0
}

# Access values
print(person1["name"])  # "Alice"

# Add or update
person1["instrument"] = "piano"
person1["age"] = 26
```

You look a value up by its **key**, not by position. If these chords were in song order, a list would be right. A dictionary is right when you want "what notes are in Am?"

```python
chords = {
    "C": ["C", "E", "G"],
    "G": ["G", "B", "D"],
    "Am": ["A", "C", "E"],
}

# Test yourself:
test0 = chords["Am"]
print(f"test0 = {test0}")  # What will this print?

test1 = chords["E"]
print(f"test1 = {test1}")  # What will this print?

test2 = chords["am"]
print(f"test2 = {test2}")  # What will this print?
```

## <span id="loops">Loops</span>

A `for` loop walks through every item in a list, one at a time.

```python
chord = ["C", "E", "G"]

for note in chord:
    print(note)
```

## Conditionals

An `if` statement runs code only when a condition is true. Use `==` to check equality, then `elif` ("else if") and `else` for the other cases.

```python
beats_per_measure = 4

if beats_per_measure == 4:
    print("common time")
elif beats_per_measure == 3:
    print("waltz")
else:
    print("something else")
```
