## 9. Print from a function

Define a function named `hello` that accepts a single input.

- For the input `"alice"`, the function should **print** `hello alice!`.
- For the input `"bob"`, the function should **print** `hello bob!`.
- **Hint**: you may use f-string syntax: `f"{name}"`.

<PyScriptEditor
  kind="py-editor"
  rows={10}
  outputRows={2}
  initialCode={`
`}
  verifyCode={`
import io
import sys

def _printed(name):
    buf = io.StringIO()
    old = sys.stdout
    sys.stdout = buf
    hello(name)
    sys.stdout = old
    return buf.getvalue().strip()

alice = _printed("alice")
assert alice == "hello alice!", f"hello('alice') printed {alice!r}"
bob = _printed("bob")
assert bob == "hello bob!", f"hello('bob') printed {bob!r}"
print("✓ Correct!")
`}
/>
