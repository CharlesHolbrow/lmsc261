## Requirements

- Start from the class demo: numpy sine, write a `.wav` file, play it in Interactive, plot it.
- The wav is a **melody**, not one long note.
- At least **six different notes** (six different frequencies). They do not have to be equal-tempered, but they can be.
- Join the note arrays with **`np.concat`**. That is the point of this assignment.

Each note is its own array, the same way class made `samples`. `np.concat` lines those arrays up in time:

```python
samples = np.concat([note1, note2, note3, note4, note5, note6])
```

Make six notes at different frequencies, then concat them. Piano pitches are fine; so are any six frequencies you can hear as different notes. You can keep each note one second, or shorten `t` so the melody moves faster.

The plot can stay. You may need a larger `xlim` than `0.01` if you want to see more than one note.
