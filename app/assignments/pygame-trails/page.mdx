## Part 4: Mouse trail

Keep the last 50 mouse positions and draw a circle at each one. Put the list
**above** the loop so it is not recreated every frame.

Under `# State`, replace `pos` with:

```python
LENGTH = 50
history = [(0, 0)] * LENGTH  # shortcut: a list of 50 copies of (0, 0)
```

`[(0, 0)] * LENGTH` is the same as appending `(0, 0)` fifty times.

Delete `pos = pygame.mouse.get_pos()` from Part 3. You will read the mouse when
you insert into `history`.

After the event loop, before `screen.fill` (same indent as `screen.fill`):

```python
    history.insert(0, pygame.mouse.get_pos())
    history.pop()
```

That puts the newest point at index `0` and drops the oldest off the end.

Replace the code **between** `# Drawing` and `# End drawing`. Keep the comments.
Fill in `???`:

```python
    for i in range(LENGTH):
        pos = history[???]
        pygame.draw.aacircle(screen, (255, 0, 0), pos, i // 2 + 1)
```

Leave `screen.fill` in. If you comment it out, leftover pixels look like a
trail even when the list is wrong.

Move the mouse. You should get a trail of circles.

**Run** the code and confirm the trail. Then **Commit** — `Part 4: mouse trail`

## Part 5: Color and window size

Pick a window size you like, and color the trail yourself.

`WIDTH` and `HEIGHT` are the window size in pixels. Change them at the top of
`main.py`. `800` by `600` is a reasonable starting point.

The second argument to `aacircle` is the color: `(red, green, blue)`, each from
`0` to `255`. In the draw loop, `i` is `0` for the newest point and grows
toward the oldest. You can use `i` in the color so the trail changes along its
length. Example:

```python
pygame.draw.aacircle(screen, (255, i * 4, 0), pos, i // 2 + 1)
```

That example is red-to-orange. Use your own numbers. The circles should not all
be the same color.

**Run** the code and confirm a window size and colors you chose. Then
**Commit** — `Part 5: color and window size`
