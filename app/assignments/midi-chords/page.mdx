## main.py

Notes that share a start time play together. That is a chord. `time` and `duration` are in beats.

```python
from midiutil import MIDIFile

midi = MIDIFile(1)
midi.addTempo(0, 0, 120)

def add_chord(note_numbers, time, duration):
    for note_number in note_numbers:
        midi.addNote(0, 0, pitch=note_number, time=time, duration=duration, volume=100)

add_chord([60, 64, 67], 0, 2)

with open("progression.mid", "wb") as output_file:
    midi.writeFile(output_file)
```

The example writes one chord. Take your chord progression from [Basic Chords](/assignments/basic-chords/) and generate a MIDI file that contains at least that progression. Longer or more elaborate is fine. 

Put the chords in a list, then iterate over the list. Each call to `add_chord` needs a later `time` than the one before it, or the chords stack on top of each other.
