# Git Glossary

It will be helpful to know the following terms:

- **Repository (repo)**: A directory of files and folders that are tracked by Git.
- **Commit**: A snapshot of the repository at a specific point in time.
- **Branch**: A a collection of related commits.
- **Pull Request (PR)**: A request to merge a branch into the main branch.

What can you do with **branches** and **commits**?

- **Merge**: The process of combining branches, often into the main branch.
- **Push**: The process of uploading changes to a remote repository.
- **Pull**: The process of downloading changes from a remote repository.
- **Fetch**: The process of downloading changes from a remote repository without merging them.
