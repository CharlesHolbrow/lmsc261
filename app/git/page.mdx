# Git & GitHub

You Must have a GitHub account to access the course content.

1. Create a GitHub account at [GitHub](https://github.com/).
1. Download and install the [GitHub Desktop](https://github.com/apps/desktop) application.
1. Sign in to the course page with your GitHub account: <GitHubSignIn redirectTo="/git/" />
1. Let your instructor know when you have signed in.
1. Your instructor will send you [two invitations to your GitHub account](https://github.com/notifications?source=search_bar&query=is%3Arepository-invitation+).

<div className="text-xl font-bold text-center my-8">
You must <span className="text-teal-600">accept both GitHub invitations</span>
to access class materials and submit homework.
</div>
