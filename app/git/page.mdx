# What is Git?

`git` is a tool for storing the **undo history** of code.

You will use `git` to store "undoable" snapshots as you make changes to code.

To understand `git`, it will be helpful to know the following terms:

- **Repository (repo)**: A directory of files and folders that are tracked by Git.
- **Commit**: A snapshot of the repository at a specific point in time.
- **Branch**: A a collection of related commits.

What can you do with **branches** and **commits**?

- **Merge**: The process of combining branches, often merging new features into the main branch.
- **Push**: The process of uploading changes to a remote (e.g. GitHub) repository.
- **Pull**: The process of downloading changes from a remote (e.g. GitHub) repository.
- **Pull Request (PR)**: A request to merge a branch into the main branch.

You will submit your assignments with PRs.
